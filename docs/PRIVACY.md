# الخصوصية والبصمة — بصدق كامل

Ghost يخفي **بصمة المتصفح** بشكل عميق ومتسق، لكن هناك حدوداً فيزيائية لا يتجاوزها أي
متصفح في العالم. هذه الوثيقة تقول لك بالضبط ما الذي يتغير وما الذي لا يتغير.

## ما الذي يغيّره Ghost فعلاً (ومُتحقَّق منه آلياً في `npm run smoke`)

| الإشارة | كيف | العمق |
|---|---|---|
| الكوكيز/التخزين/الكاش | partitions منفصلة لكل تاب/قروب | كامل (لا شيء مشترك) |
| المنطقة الزمنية (`Date`, `Intl`) | CDP `Emulation.setTimezoneOverride` | عميق (محرك المتصفح) |
| اللغة و`Accept-Language` | session UA + حقن ترويسات | كامل |
| User-Agent وclient-hints (`sec-ch-ua*`) | session + CDP metadata + ترويسات | متسق عبر كل الطلبات |
| الموقع الجغرافي (Geolocation API) | CDP `setGeolocationOverride` بإحداثيات المدينة ± jitter | كامل |
| `navigator.platform/languages/hardwareConcurrency/deviceMemory` | سكربت main-world عند document-start | كامل |
| شاشة و`devicePixelRatio` | سكربت main-world | كامل |
| WebGL vendor/renderer | اعتراض `getParameter` | كامل |
| تسريب WebRTC المحلي | فرض `iceTransportPolicy: relay` أو تعطيل كامل | كامل |
| بصمة Canvas | ضجيج ببذرة ثابتة (اختياري) | جزئي (قد يكسر مواقع) |

## ما الذي **لا** يغيّره Ghost (ولا أي متصفح)

1. **عنوان IP ودولته.** الموقع يرى مزوّد خدمتك الحقيقي مهما غيّرت التوقيت.
   الحل الصحيح والوحيد: **بروكسي لكل قروب** (socks5/http مدعومان في إعدادات القروب)،
   وعندها فقط سيظهر القروب "أ" من أمريكا حقاً. مختبر التسريبات يوضح هذا السطر تحديداً.
2. **بصمات مستوى الشبكة** (TTL، JA3/TLS fingerprint) — تحتاج بروكسي متخصص.
3. **سلوكك**: نفس كلمة المرور، نفس البريد، نفس طريقة الكتابة = ربط حسابات بغض النظر عن البصمة.
4. **الأنظمة المضادة القوية** (مثل بعض حلول البنوك) قد تطلب إشارات إضافية.

## قواعد ذهبية للاستخدام متعدد الحسابات

- قروب واحد = حساب واحد = بروكسي واحد ثابت (لا تبدّل دولة الحساب بعد تسجيل الدخول).
- اجلس على الحساب من نفس القروب دوماً (وضع "مشترك" أو "محفوظ") ولا تفتحه من شبح عشوائي.
- لا تنسخ/تلصق بين القروبات عبر حافظة مشتركة أثناء تسجيل الدخول.
- اختبر قبل الاعتماد: افتح `ghost://leaktest` داخل القروب وتأكد أن كل الأسطر ✓ أو "معلومة".

## ماذا يرى المطورون في وضع التطوير؟

لا شيء يُرسل لأي خادم منا: لا telemetry، لا تحليلات، لا اتصال خارجي إلا لما تفتحه أنت
أو لتحديث القوائم/التحديث التلقائي (GitHub Releases). كل البيانات تبقى في
`userData` على جهازك، وحذف قروب يمسح partition الخاص به كاملاً.
